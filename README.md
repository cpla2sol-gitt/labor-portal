# 노무 서식 포털 — HR Document Portal

> 채용부터 퇴직까지, 노무관리에 필요한 서식을 온라인으로 작성하고 바로 PDF·Word로 출력하는 웹 포털입니다.  
> 결재라인·회사 정보를 한 번만 설정하면 전체 서식에 자동 반영됩니다.

🔗 **배포 주소:** `https://cpla2sol-gitt.github.io/labor-portal/`

## 📁 파일 구성

```
labor-portal/
├── index.html                 — 메인 페이지 (레이아웃·사이드바·홈 화면·설정 모달·편집기 패널·편집 이력 패널)
├── .nojekyll                  — GitHub Pages의 Jekyll 처리 비활성화
└── assets/
    ├── style.css              — 전체 스타일 (CSS 변수 기반, A4 화면·인쇄 규격 포함)
    │
    ├── forms-recruit.js       — [채용] 서식 2종
    ├── forms-employed.js      — [재직] 서식 9종
    ├── forms-retire.js        — [퇴직] 서식 6종
    ├── forms-leave.js         — [휴가] 서식 2종
    ├── forms-discipline.js    — [징계] 서식 9종
    ├── forms-education.js     — [교육] 서식 4종
    ├── forms-etc.js           — [기타] 서식 2종
    │
    ├── app.js                 — 네비게이션 · 결재란 · 회사 정보 설정 · PDF 전체 출력
    ├── editor.js              — 디자인 편집기 (색상·글자 크기·로고·여백)
    ├── form-editor.js         — 서식 편집 모드 (텍스트·표 구조 직접 수정)

```

## ⚙ 주요 기능

### 회사 정보 일괄 설정
우상단 **⚙ 설정** 버튼에서 회사명·대표자명·사업장 소재지를 한 번만 입력하면 전체 서식의 빈 칸에 자동 반영됩니다. 사업자등록번호·대표 연락처도 함께 저장할 수 있습니다. 자문사(고객사)가 바뀔 때마다 여기서만 변경하면 됩니다.

### 결재라인 설정
설정에서 기본 결재라인을 1단계(대표) ~ 4단계(담당→팀장→본부장→대표) 중에서 지정합니다. 신청서류(사직원·출장신청서 등)에는 기본 결재란이 표시되고, 증명서·통지서류는 기본값이 "없음"입니다. 어느 서식이든 툴바의 **결재: 없음 / 1–4단계** 토글로 개별 변경할 수 있습니다.

### 출력
| 버튼 | 위치 | 동작 |
|------|------|------|
| **PDF 출력** | 서식 툴바 | 현재 서식 1장을 인쇄 대화상자로 출력 |
| **Word 출력** | 서식 툴바 | 현재 서식을 `.docx`로 저장 (A4, 맑은 고딕) |
| **PDF 전체 출력** | 헤더 | 34종 전체를 A4 한 장씩 일괄 출력 |
| **Word 전체 출력** | 헤더 | 34종 전체를 페이지 나누기로 구분한 `.docx` 1개로 저장 |

전체 출력 시 저장된 편집본이 있는 서식은 편집본으로 출력됩니다. 인쇄 시에는 서명란이 A4 하단에 고정되도록 자동 보정됩니다.

### 서식 편집 모드
서식 툴바의 **✏ 서식 편집** 버튼으로 서식 문구와 표 구조를 직접 수정할 수 있습니다.

- 제목·본문·표 셀·결재란 직급 등 텍스트를 클릭해 바로 수정
- 셀 클릭 시 포맷 툴바 표시 — 글자 크기, 굵게·기울임·밑줄, 정렬, 셀 배경색, 행 높이, 열 추가·삭제
- 표 헤더 경계를 드래그해 열 너비 조절, 행 하단 경계를 드래그해 행 높이 조절
- 행 오른쪽 **+ / ×** 버튼으로 행 추가·삭제
- **💾 이 서식 저장**으로 브라우저에 저장 → 다음에 열 때 편집본이 자동으로 불러와짐
- **↺ 초기화** 시 저장된 편집본을 삭제하고 기본 서식으로 되돌릴지 확인

### 편집 이력
**📋 편집 이력** 버튼에서 서식별로 저장한 버전을 확인합니다. 서식당 최대 10개 버전이 자동 보관되며, 각 버전을 미리보기하거나 복원할 수 있습니다.

### 디자인 편집기
헤더의 **디자인** 버튼으로 열 수 있습니다. 변경 사항은 실시간으로 반영됩니다.

| 항목 | 편집 가능 내용 |
|------|----------------|
| 색상 테마 | 헤더·사이드바·강조색·페이지 배경·라벨 셀·헤더 셀·결재란·텍스트 / 5종 프리셋(네이비·포레스트·버건디·슬레이트·모노) |
| 로고 | 이미지 업로드(PNG·JPG·SVG), 로고 문자, 사이트명, 부제목 |
| 서식 크기 | ① 제목(12–28pt) ② 분류명(7–15pt) ③ 내용(7–15pt) ④ 기타(7–15pt), 셀 높이, 서명란 너비(80–220pt), 제목 구분선 두께(1–4pt) |
| A4 여백 | 상하(10–40mm), 좌우(10–35mm) |
| CSS 내보내기 | 현재 설정을 `style.css`의 `:root {}` 교체용 코드로 클립보드 복사 |

## 🚀 배포 방법 (GitHub Pages)

1. 저장소 **루트**에 `index.html`, `.nojekyll`, `assets/` 폴더를 위 파일 구성 그대로 업로드
2. **Settings → Pages → Branch: main → Save**
3. 1–2분 후 `https://{계정명}.github.io/{저장소명}/` 접속

> ✅ 별도 서버 불필요 — 정적 파일만으로 동작  
> ✅ GitHub Pages 무료 플랜으로 운영 가능  
> ✅ `index.html`이 CSS·JS 파일에 타임스탬프를 붙여 불러오므로, 파일을 수정해 올리면 브라우저 캐시 없이 바로 반영됩니다.

## 🔧 코드 수정 가이드

### 서식 추가하기
**1단계** — 해당 분류의 `assets/forms-*.js` 파일에 새 항목 추가  
(각 파일은 `Object.assign(window.FORMS, { ... })` 형태로 전역 `FORMS` 객체에 서식을 등록합니다.)
```js
'my-form': {
  title: '서식 이름',
  sub: '근거 법령 또는 안내 문구',  // 툴바 제목 아래 표시
  hasApproval: true,    // true: 기본 결재란 표시 / false: 기본 "없음"
  notice: '상단 공지',  // 빈 문자열이면 공지 숨김, \n으로 줄바꿈
  html: () => `...`     // 서식 HTML 반환 함수
}
```
회사 정보를 자동 입력하려면 입력칸에 `c-company`, `c-ceo`, `c-addr` 클래스를 붙입니다.

**2단계** — `index.html` 사이드바에 메뉴 항목 추가
```html
<div class="sb-item" id="m-my-form" onclick="go('my-form')">
  <span class="n">35</span>새 서식 이름
</div>
```

**3단계** — `index.html` 홈 화면(`.home-grid`)의 해당 분류 카드에도 항목 추가  
(필요하면 히어로 영역의 서식 개수 `34`도 함께 수정)

> 새 분류 파일(`forms-새분류.js`)을 만들었다면 `index.html` 하단 스크립트 로드 목록에 `app.js`보다 **앞에** 추가해야 합니다.

### 색상·크기 코드로 수정하기
`assets/style.css` 상단 `:root {}` 블록의 CSS 변수를 직접 수정합니다. (디자인 편집기의 **CSS 내보내기**로 만든 코드를 그대로 붙여넣어도 됩니다.)

```css
:root {
  --navy-dk:      #0d2137;  /* 헤더·주요 버튼 배경 */
  --navy:         #1b3a5c;  /* 사이드바 배경 */
  --gold:         #c8a354;  /* 강조 색상 */
  --sidebar-w:    252px;    /* 사이드바 너비 */
  --a4-pad-v:     27mm;     /* A4 상하 여백 */
  --a4-pad-h:     27mm;     /* A4 좌우 여백 */
  --title-font:   18pt;     /* ① 제목 */
  --label-font:   11.5pt;   /* ② 분류명 (라벨·헤더 셀) */
  --content-font: 11.5pt;   /* ③ 내용 (입력값·본문) */
  --etc-font:     11.5pt;   /* ④ 기타 (블록박스·섹션 레이블) */
  --cell-pad-v:   6pt;      /* 테이블 셀 높이 (상하 패딩) */
  --sign-w:       170pt;    /* 서명란 너비 */
  --doc-border:   2pt;      /* 제목 하단 구분선 두께 */
}
```
디자인 편집기의 **기본값 초기화** 기준은 `assets/editor.js`의 `DEFAULT_DESIGN` 객체에서 바꿀 수 있습니다.

### 결재란 직급 변경하기
`assets/app.js`의 `AP_LABELS` 객체를 수정합니다.
```js
const AP_LABELS = {
  1: ['대표'],
  2: ['팀장', '대표'],
  3: ['담당', '팀장', '대표'],
  4: ['담당', '팀장', '본부장', '대표']
};
```

### 이용 로그 끄기
`assets/log.js`의 `LOG_ENDPOINT`를 빈 문자열(`''`)로 바꾸면 로그 전송이 중단됩니다.

## 💾 데이터 저장 및 전송

**브라우저에 저장되는 데이터 (localStorage)**

| 키 | 내용 |
|----|------|
| `laborPortalSettings` | 회사 정보·기본 결재라인 |
| `laborPortalDesign` | 디자인 편집기 설정 |
| `fe_[서식ID]` | 서식별 저장된 편집본 |
| `fe_history_[서식ID]` | 서식별 편집 이력 (최대 10개) |

위 데이터는 사용자마다 각자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 서식에 입력한 내용(성명·주민번호 등)도 전송되지 않습니다.

**이용 로그 (log.js)**

포털 접속, 서식 조회·편집 저장·PDF 출력·전체 출력·버전 복원 시 아래 정보가 Google Apps Script를 통해 관리자의 Google Sheets로 전송됩니다.

- 일시, 서식 ID·서식명, 행동 유형
- IP 주소·국가·도시 (ipapi.co 조회)
- 브라우저·OS·화면 해상도·언어·유입 경로(referrer)
